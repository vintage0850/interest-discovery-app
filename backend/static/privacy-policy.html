3. Google API サービスの使用に関する開示（Google API Services User Data Policy）

本アプリのGoogleカレンダー機能の使用は、 Google API Services User Data Policy のLimited Use（限定的な使用）要件を遵守します。具体的には：

  • 取得したカレンダーデータは、本アプリの「タスクの締切をカレンダーに表示する」機能のためだけに使用します。
  • 広告目的での使用、第三者への販売・共有、人間による閲覧（デバッグ・不正利用の調査などを除く）は行いません。
  • 要求するスコープは https://www.googleapis.com/auth/calendar.events（予定の読み書きのみ）で、カレンダーの完全な読み取り権限（calendar フルスコープ）は要求しません。

4. AI（Google Gemini API）によるデータ処理について

Discovery機能でユーザーが入力したアンケート回答やふりかえりの記述は、行動実験の提案やレポートを自動生成するために、当社サーバーを経由してGoogleのGemini APIに送信されることがあります。送信されるデータには氏名・メールアドレス等の直接的な個人識別情報は含まれません。Gemini APIへの送信データの取り扱いはGoogleのプライバシーポリシーおよび利用条件に従います。

5. データの共有

本アプリは収集した情報を第三者に販売しません。Googleカレンダーへの書き込みは、ユーザー自身のGoogleアカウントに対して、Googleの公式API経由で行われます（この通信にはGoogle自身のプライバシーポリシーが適用されます）。Discovery機能のデータは、提案生成のためGoogleのGemini APIに送信される場合があります（第3項・第4項参照）。

6. データの削除

  • タスクデータ: アプリ内でタスクを削除する、またはアプリをアンインストールすることで端末から削除されます。
  • Discovery機能のデータ: アプリ内の設定画面からデータのリセットを行うことで削除を要求できます。
  • カレンダー連携の解除: アプリ内の連携解除操作、または Googleアカウントのアクセス権限ページ からいつでも取り消せます。連携を解除しても、それまでにカレンダーへ作成済みの予定は自動削除されません（本アプリが作成した予定のみ、アプリ内操作で個別に削除できます）。
  • 上記操作で削除できない場合や、サーバー側のデータの削除を個別に依頼したい場合は、第8項の連絡先までご連絡ください。

7. 未成年者の利用

本アプリは学齢・年代の任意入力欄を備えていますが、特定の年齢層のみを対象とした設計は行っていません。保護者の方は、お子様がアプリを利用する際に本ポリシーの内容をご確認ください。

8. 本ポリシーの変更
